# Петелька — прототип M0

Спокойная игра про вязание на спицах. Canvas 2D + чистый JS, без сборки.

## Как открыть
- Самое простое: открыть `index.html` в браузере (работает и по `file://`).
- Как на телефоне (с офлайн-кэшем): `python3 -m http.server 8080` в этой папке → http://localhost:8080
- На iPhone (позже, после «да» на публикацию): GitHub Pages → Safari → «Поделиться» → «На экран Домой».

## Отладка
- `?level=N` — сразу уровень N (1–5)
- `?speed=0.25` — замедление в 4 раза (видно фазы петли A–E)
- `?nosw` — без service worker
- В консоли: `__petelka.state()`, `__petelka.tap(i)`, `__petelka.hint()`, `__petelka.pause(true)` + `__petelka.advance(20)` (покадрово), `__petelka.fpsStart()/fpsStop()`
- Прогресс хранится в `localStorage['petelka.m0']`. Сброс: `localStorage.clear()`.

## Файлы
- `src/stitch.js` — процедурная петля (штрих по пути, ножки/сужение/головка, скрутка, пух, люрекс), атлас спрайтов
- `src/scene.js` — фон, корзинка, клубки, спицы, нить (Verlet), частицы
- `src/game.js` — раскладка, очередь анимаций A–E, UI, «Ряд готов», узор, «Снято со спиц», карточка
- `src/logic.js` — правила + решатель (подсказки, тупики)
- `data/levels.js` — уровни 1–5 из `../levels.json`
